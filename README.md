# Grade 7 Texas History — Fall Semester

GitHub-Pages-hosted lesson content and interactive widgets for Optima Academy Online's
Grade 7 Texas History course (TEKS 19 TAC §113.19(b)), Fall semester, Quarters 1–2 (Weeks 1–18).

- `quarter-1/week-01` … `week-09` — Q1, "The Spanish Experiment"
- `quarter-2/week-10` … `week-18` — Q2, "The English Experiment"
- `widgets/` — standalone interactive widgets embedded via iframe in the lesson pages above

These pages are embedded into Canvas via thin iframe wrapper pages; they are not meant to be
browsed as a standalone site, though every page works fine loaded directly.
